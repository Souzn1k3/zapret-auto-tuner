# Zapret Auto-Tuner

Zapret Auto-Tuner — это сверхбыстрый скрипт для автоматического подбора рабочих конфигураций (пресетов) [Zapret](https://github.com/bol-van/zapret) на ОС Windows. 

Если ваш провайдер меняет методы блокировки (ТСПУ) и старые способы обхода перестают работать, этот скрипт берет на себя всю рутину. Он автоматически перебирает батники Запрета, параллельно проверяя доступность заблокированных сайтов, пока не найдет рабочий вариант.

## Как это работает?
Вместо того чтобы вручную запускать каждый `.bat` файл и проверять в браузере, открывается ли YouTube или Discord, тюнер делает это за вас со скоростью машины:
1. Запускает первый пресет (например, `general.bat`).
2. Одновременно стучится на заданные сайты (Discord, YouTube, Twitter и др.).
3. Если получает блокировку по DPI (Connection Reset / Timeout) хотя бы от одного сайта — мгновенно убивает процесс `winws.exe` и запускает следующий пресет (`general (ALT).bat`).
4. Повторяет до тех пор, пока все сайты не ответят статусом `200 OK`.

## 🚀 Установка (Без использования Python)

Вам **не нужно** устанавливать Python. Достаточно скачать один `.exe` файл!

1. Перейдите в раздел **Releases** справа и скачайте `zapret-auto-tuner.exe` (или скачайте репозиторий и найдите файл внутри).
2. Положите файл `zapret-auto-tuner.exe` в любую удобную вам папку.
3. Запустите его **от имени Администратора** в первый раз.
4. Программа закроется и создаст рядом с собой файл `config.ini`.
5. Откройте `config.ini` в Блокноте и впишите абсолютный путь к папке вашего Запрета (туда, где лежат ваши батники). Например:
   `ZapretDir = C:\Users\damic\Desktop\vpn\Запретик\zapret-discord-youtube-1.9.7b`
6. Снова запустите `zapret-auto-tuner.exe` **от имени Администратора**. Тюнер начнет перебор!

### ⚙️ Запуск из исходного кода (Для разработчиков)
Если вы хотите запустить скрипт через Python:


## Настройка автозагрузки (Один раз и навсегда)
Вам **не нужно** запускать этот тюнер каждый день! Как только он найдет рабочий батник:
1. Зайдите в папку вашего Запрета.
2. Найдите файл, который подобрал скрипт (например, `general (ALT).bat`).
3. Создайте для него ярлык.
4. Нажмите `Win + R`, введите `shell:startup` и переместите туда ярлык.
5. Готово! Теперь ваш интернет всегда будет работать без блокировок автоматически при включении ПК. А к скрипту тюнера можно вернуться только если провайдер снова сломает обход.

## ❓ FAQ (Частые ошибки и вопросы)

**Q: Скрипт мгновенно закрывается, ничего не написав.**
A: Откройте командную строку (cmd) от имени Администратора, перетащите туда файл `zapret-auto-tuner.exe` и нажмите Enter. Тогда окно не закроется, и вы увидите текст ошибки. Чаще всего ошибка в неправильно указанном пути в `config.ini`.

**Q: Пишет "Папка Zapret не найдена по пути..."**
A: Убедитесь, что вы скопировали правильный путь к папке Запрета. Путь не должен заканчиваться пробелом. Пример правильного пути: `C:\Users\Ivan\Desktop\zapret-winws`.

**Q: Тюнер перебрал все 19 вариантов, но написало "All 19 presets exhausted".**
A: Это значит, что ни один из стандартных пресетов вашей сборки Запрета не смог обойти блокировку провайдера. Попробуйте обновить сам Запрет (скачать новую версию с GitHub bol-van), либо ваш провайдер блокирует слишком жестко и требуются кастомные аргументы (Custom Hex).

**Q: Почему требуется Запуск от имени Администратора?**
A: Zapret (файл `winws.exe`) вмешивается в системные сетевые пакеты Windows на низком уровне. Без прав Администратора он просто не сможет работать, поэтому наш тюнер тоже должен запускаться с правами Администратора, чтобы иметь возможность убивать и перезапускать процесс.

## Безопасность
Скрипт полностью безопасен и ограничен "песочницей". Он использует строгий White-list из 19 разрешенных `.bat` файлов Запрета и защищен от Path Traversal, что исключает возможность запуска вредоносного кода или случайного повреждения системы.
